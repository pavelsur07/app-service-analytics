# Links: встроенный сокращатель ссылок

**Дата:** 2026-09-03
**Статус:** согласовано для планирования
**Модуль:** Links (новый)

## Цель

Добавить на `lin.conwix.com` короткие отслеживаемые ссылки для
собственных рассылок и кампаний Conwix. Администратор создаёт и
редактирует ссылки в `apps/admin`, а также смотрит число человеческих
переходов по дням выбранного месяца.

Нагрузка внутренняя, порядка сотен переходов в сутки. Новых контейнеров,
языков, очередей или кэшей не появляется.

## Границы MVP

Входит:

- создание ссылки из названия и целевого URL;
- ограниченный список, копирование короткого URL;
- изменение названия и цели;
- отключение и повторное включение;
- публичный `302`-редирект;
- сырые события переходов с признаком бота;
- таблица «дата → число переходов» за выбранный месяц;
- dev- и production-маршруты Traefik/nginx без новых сервисов.

Не входит:

- произвольный код ссылки;
- удаление ссылок или кликов;
- UTM-builder, QR-коды, bulk import/export;
- география, устройства и дедупликация переходов;
- автоматическое удаление сырых событий;
- денормализованные счётчики, rollup-таблица, Redis и Messenger.

## Рассмотренные варианты реализации

### 1. ORM для ShortLink, DBAL для ShortLinkClick — выбрано

`ShortLink` редактирует человек: ORM даёт версию и атомарный `flush`
с аудитом. Первичную вставку репозиторий делает через DBAL
`INSERT ... ON CONFLICT (code) DO NOTHING`: так коллизию можно повторить, не
закрывая EntityManager исключением Doctrine. Это узкое исключение;
последующие человеческие правки остаются ORM-операциями.

`ShortLinkClick` только дописывается: DBAL не держит его в Unit of Work,
а месячную агрегацию выполняет PostgreSQL. Обеим таблицам соответствуют
Doctrine Entity-классы для валидации маппинга и тестовых Builder.

### 2. Только DBAL — отклонено

Снижает стоимость одной вставки, но вынуждает вручную повторить optimistic locking,
гидрацию и атомарную запись аудита.

### 3. Только ORM — отклонено

Гидрация событий для статистики и Unit of Work на публичной записи не дают
выгоды и противоречат правилу проекта для факт-таблиц.

## Границы модуля

Новый `api/src/Links` состоит из `Domain`, `Application`, `Infrastructure` и `Ui`.
Модуль владеет ссылками, кликами, детектором ботов и статистикой.

`Links` зависит от `Shared` и от одного узкого контракта `Identity`:
`IdentityAdminFacade`. У него две связанные операции границы: получить UUID
администратора по аутентифицированному identifier и поставить в Unit of Work
аудит с UUID администратора, action, UUID ссылки и «было/стало». Компании
у этого системного события нет. Возвратной зависимости `Identity → Links` нет.
Deptrac выдаёт `LinksUi` и `LinksApplication` доступ только к этому фасаду,
а не ко всему `IdentityApplication`.

Admin-контроллер читает только стандартный `UserInterface::getUserIdentifier()`
и через фасад получает UUID для Application. Ни один слой Links не импортирует
сущности Identity напрямую.

## Данные

### short_link

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `uuid`, PK | UUIDv7 |
| `code` | `varchar(7)`, unique | неизменяемый base62-код |
| `name` | `varchar(120)` | название для админки |
| `target_url` | `varchar(2048)` | абсолютный HTTP(S) URL |
| `status` | `varchar(16)` | `active` или `disabled` |
| `version` | `integer` | ORM optimistic lock, начинается с 1 |
| `created_by_admin_id` | `uuid` | scalar-ссылка на Identity |
| `created_at` | timestamp | момент создания |
| `updated_at` | timestamp | момент последней правки |

Индексы: unique по `code`, список по `(created_at, id)` и индекс по
`created_by_admin_id`. Внешний ключ автора защищает ссылку на существующего
администратора, но ORM-ассоциации между модулями нет.

Ссылки не удаляются. Создание оставляет достаточный след в этой же строке:
автор и время. Правка цели/названия и обратимая смена статуса теряют
прежнее значение, поэтому обязательны версия и audit record с «было/стало».

### short_link_click

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `uuid`, PK | UUIDv7 события |
| `short_link_id` | `uuid`, FK | ссылка, по которой перешли |
| `clicked_at` | timestamp | время события |
| `user_agent` | `varchar(1024)`, nullable | ограниченное сырое значение |
| `referer` | `varchar(2048)`, nullable | ограниченное сырое значение |
| `is_bot` | `boolean` | классификация в момент клика |

Индекс `(short_link_id, clicked_at)` обслуживает месячную агрегацию. Событие никогда не
изменяется и не удаляется в MVP. IP-адрес не сохраняется.

`User-Agent` и `Referer` — недоверенные заголовки. Перед записью пустые значения
превращаются в `null`, а непустые обрезаются по лимиту колонки, чтобы заголовок
не мог сорвать учёт клика. Исходного IP нет ни в БД, ни в логе приложения.

## Код и боты

Код состоит ровно из семи символов `0-9A-Za-z`. Генератор использует
криптографическую случайность без modulo bias. Уникальный индекс — окончательная
защита; коллизия повторяет генерацию до пяти раз, после чего запрос завершается
контролируемым `503`, а не повтором без границы.

Первичный фильтр ставит `is_bot=true`, если `User-Agent` пуст или содержит
признаки crawler, spider, bot, preview/scanner, headless-клиента или CLI/HTTP-библиотеки.
Конкретный список признаков живёт в одном чистом доменном классе. Все события
сохраняются; админская статистика считает только `is_bot=false`.

## HTTP API

### Публичный маршрут

`GET /{code}` привязан атрибутом Symfony Route к хостам
`lin.conwix.com`, `lin.conwix.localhost` и `lin.conwix.internal`. Требование к пути пропускает
только base62-код длины 7.

Поток:

1. найти активную ссылку по code;
2. если её нет, вернуть `404`;
3. построить событие и синхронно попытаться вставить его через DBAL;
4. при любом отказе только вставки записать warning без заголовков и продолжить;
5. вернуть `302` на цель с `Cache-Control: no-store`.

Отказ lookup не подавляется: без прочитанной цели редирект невозможен. Если
ссылку отключили между lookup и ответом, один уже начатый запрос может завершиться
редиректом; граница отключения — новые lookup, а не блокировка уже летящих запросов.

### Admin API

Все маршруты ниже находятся под `/api/admin/links`, попадают на существующий admin-firewall
и имеют `#[IsGranted('ROLE_ADMIN')]`:

| Метод и путь | Смысл |
|---|---|
| `POST /api/admin/links` | создать из `name`, `targetUrl`; ответ `201` |
| `GET /api/admin/links?page=&limit=` | список, 50 по умолчанию, 200 максимум |
| `POST /api/admin/links/{id}` | изменить `name`, `targetUrl`, `version` обязательна |
| `POST /api/admin/links/{id}/status` | задать `active/disabled`, `version` обязательна |
| `GET /api/admin/links/{id}/clicks?month=YYYY-MM` | человеческие переходы по дням |

Список и статистика читаются SQL-запросами DBAL в `readonly` DTO, без гидрации
сущностей. Список сортируется по `created_at DESC, id DESC` и ограничен пагинацией.
Короткий URL строится из code, а не хранится.
Базовый адрес задаётся конфигурацией `LINKS_PUBLIC_BASE_URL`:
`https://lin.conwix.com` в production и `http://lin.conwix.localhost` в dev/test.

Одиночный ответ ссылки и каждый item списка содержат `id`, `code`, `shortUrl`,
`name`, `targetUrl`, `status`, `version`, `createdAt` и `updatedAt`. Ответ списка
дополнен `total`, `pages`, `page` и `perPage`. Ответ статистики содержит
`linkId`, `month` и `items`; каждый item — `date` в `YYYY-MM-DD` и целое `clicks`.

Месяц разбирается строго как `YYYY-MM` в UTC. Прошлый месяц возвращает каждый
календарный день, включая нулевые; текущий — с первого числа по сегодня. Будущий
месяц не принимается.

Валидация:

- `name` после `trim` — от 1 до 120 символов;
- `targetUrl` — абсолютный URL длиной не больше 2048 символов со схемой `http` или `https`;
- URL с userinfo (`https://user:password@host`) отклоняется, чтобы учётные данные не попали
  в список, аудит и `Location`;
- `version` — положительное целое.

Если mutation получила текущую version, но целевые значения уже совпадают,
она возвращает текущую ссылку без новой версии и без аудита. Устаревшая version
всегда даёт `409`, даже если желаемое состояние уже достигнуто: клиент обязан
перечитать данные после чужой правки.

Ответы:

- `404` — ссылка не найдена или public code не активен;
- `409` — optimistic lock не совпал; UI показывает конфликт и перечитывает список,
  но не повторяет запись автоматически;
- `422` — некорректный JSON, поля, пагинация или месяц;
- `503` — пять коллизий code подряд;
- штатные `401/403` admin-контура.

## Admin UI

В `apps/admin/src/features/links` появляется один экран `/links`, доступный `Admin` и
`SuperAdmin`. Sidebar получает пункт «Ссылки».

Экран состоит из:

1. компактной формы создания;
2. таблицы ссылок с названием, коротким URL, целью, статусом и действиями;
3. редактирования выбранной ссылки с её текущей version;
4. выбора ссылки для статистики;
5. панели месяца со стрелками влево/вправо;
6. таблицы дней и числа неботовых переходов.

По умолчанию выбирается первая ссылка и текущий месяц. После создания новая
ссылка выбирается автоматически. Стрелка вправо неактивна в текущем месяце. Состояния
загрузки, пустого списка, ошибки и конфликта видимы; ни один отказ mutation не остаётся
молчаливым.

Типы ответов берутся только из OpenAPI. Все ключи TanStack Query строятся через
`adminQueryKey`; в ключе статистики входят link id и месяц. Сетевые вызовы идут только через
`apps/admin/src/api/client.ts`.

## Аудит и конкурентность

Правка названия/цели пишет action `short_link.details_changed`, переключение статуса —
`short_link.activated` или `short_link.disabled`. В «было/стало» попадает детерминированный JSON с
изменяемыми полями либо строка status. Сам URL не секрет; userinfo запрещён валидацией.

Изменение ссылки и AuditRecord попадают в один ORM `flush`. Проверка version до mutation даёт
быстрый ответ, а `WHERE version = ...` в ORM-записи окончательно закрывает гонку. При
`OptimisticLockException` вся транзакция, включая аудит, откатывается.

## Инфраструктура и безопасность хоста

Traefik получает третий router на тот же nginx. Production-хост имеет HTTP-router только для
редиректа на HTTPS и HTTPS-router с Let's Encrypt. На HTTPS-router вешается отдельный
middleware `links-rate-limit`: в среднем 20 запросов в секунду на source IP, burst 50.

Nginx получает отдельный `server` для `lin.*`, но не отдаёт статику и не проксирует
произвольные пути. В php-fpm уходит только regex `^/[0-9A-Za-z]{7}$`; всё остальное получает
`404`. Это не даёт обойти admin allowlist через `lin.conwix.com/api/admin/**`: общий php-fpm не означает
общую HTTP-поверхность.

В dev используются `lin.conwix.localhost` снаружи и `lin.conwix.internal` из Docker-сети.

## Отказы и наблюдаемость

В warning об отказе click insert попадают link id, code, класс исключения и request id.
`User-Agent`, `Referer`, цель и IP не логируются. Ответ остаётся `302`.

Наблюдаемые условия из ADR:

- p95 редиректа выше 100 мс или срабатывание rate limit — отдельный php-fpm pool, затем
  отдельный процесс;
- более 5 млн строк или агрегат медленнее 200 мс — суточный rollup;
- стабильно более 50% ботов — пересмотр фильтра.

Раздел не вводит новую систему метрик. Пороги используются при разборе
существующих логов и SQL-запросов.

## Тестирование

### Backend

- Unit: base62-генератор, URL-валидация, bot detector, разбор месяца.
- Integration: вставка ShortLink, повтор при коллизии code, lookup только активной
  ссылки, click insert, месячная агрегация с нулевыми днями и исключением ботов,
  optimistic locking, атомарность правки и аудита.
- Functional: admin auth/role на новых маршрутах, валидация недоверенного ввода,
  host-bound public route, `404` для disabled, `302` и `no-store`, а также `302` при искусственном отказе click writer.

На каждую сущность создаётся неизменяемый Builder. Тесты, которые только повторяют
код контроллера, не добавляются.

### Frontend

- Unit: чистые функции перехода между месяцами и граница будущего; ключ кэша включает link id
  и month.
- E2E: существующий единственный admin-сценарий дополняется созданием ссылки,
  переходом по ней с обычным browser User-Agent и проверкой дня в таблице. Отдельный
  Playwright-сценарий не заводится.

## Документация и выкладка

- Исходный ADR сохраняется как `docs/adr/0022-links-shortener-module.md` со статусом `Proposed`.
- После зелёных проверок и полной реализации он переводится в `Accepted`, реестр ADR обновляется.
- `CLAUDE.md`, `docs/structure.md` и при необходимости `docs/patterns.md` обновляют карту нового модуля и хоста.
- Операционный чек-лист получает DNS-запись, TLS/smoke-проверку, миграцию и откат.
- Новых зависимостей нет.

Миграция имеет рабочий `down()`: сначала удаляет `short_link_click`, затем `short_link`.
Применение production-миграции остаётся ручным решением человека. DNS и production-выкладка кода
не входят в локальную реализацию; задача готовит исполнимую конфигурацию.

## Критерии готовности

1. Администратор может создать, изменить, отключить и включить ссылку.
2. Код имеет ровно семь base62-символов и защищён unique-индексом.
3. Публичный маршрут не доступен на app/admin-хостах; admin API не доступен через lin-хост.
4. Активная ссылка отвечает `302` и `no-store`; отключённая — `404`.
5. Отказ вставки click не меняет редирект.
6. Все клики сохраняются, но месячная таблица считает только неботовые.
7. Все дни выбранного наступившего периода видны, включая дни с нулём.
8. Конфликт редактирования не теряет чужую правку и не оставляет ложный аудит.
9. Новый хост использует те же nginx/php-fpm и защищён rate limit 20/s, burst 50.
10. Миграция применима к пустой БД и откатывается; OpenAPI и TypeScript-типы синхронны.
