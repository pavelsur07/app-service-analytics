### Дополнительная проверка окружения и публичности

Установлен штатный системный bubblewrap 0.9.0 из репозитория Ubuntu.
Read-only probe Codex с ним также завершился `RTM_NEWADDR: Operation not permitted`.
Установка зависимости не сняла ограничение окружения; sandbox не отключался.

`gh repo view --json isPrivate` вернул false. Это противоречит основанию
CLAUDE.md §9 («репозиторий приватный»), по которому разрешены настоящие
финансовые фикстуры. Полные MPStats-данные остались только в рабочей копии;
push и публикация не выполнялись. Владелец уведомлён и запрошен способ
хранения: приватность репозитория, хранение вне публичного Git либо явное
разрешение публикации именно этих данных. Секрет GitHub Actions не извлекался.

Позднее владелец выбрал явное разрешение публикации имеющихся MPStats-фикстур;
историческая запись выше описывает состояние до этого ответа.

Также запрошено уточнение эталона ручной сверки: оставить январский критерий
или явно принять предоставленный февральский UI CSV при сохранении полного
январского API-набора. Впоследствии владелец подтвердил февральский эталон;
соответствующее замечание принято и устранено, план обновлён.
