# Этап 6. Контрольное обследование и подтверждение поставок

## Задача и результат

Подтвердить устранение исходных находок и MFA на окончательных версиях,
связать результаты тестов, независимого ревью, CI и production-артефактов.
Не переименовывать незапущенные проверки в успешные и не переписывать
исходный пользовательский `securety_chek.md`.

## Выполнение

- [x] Для каждого PR зафиксировать head/merge commit, зелёный обязательный
  CI, image/version и результат deployment. Сверить весь diff своей задачи.
- [x] P1 reset: подтверждённые RED→GREEN HTTP 200→401 старого токена,
  все компании одного пользователя, чужие токены, rollback и гонка выпуска.
- [x] P1 CSRF: действительная браузерная text/plain форма с соседнего origin
  отклонена; encoded пути, PHP-parsed multipart и GET logout не обходят защиту.
- [x] P2 extension: native Chromium проверяет trusted worker/popup,
  content script, рестарт и сохранение ограничения без повторного worker;
  исправленная версия доступна артефактом CI, минимум Chrome 140.
- [x] P3 dependencies: Composer + все 6 npm-деревьев и Go vulncheck;
  dev-зависимости включены, отрицательная проверка отказа audit сохранена.
- [x] MFA: пароль/legacy session не открывают данные; enrollment,
  recovery/regeneration, повтор кода, лимиты, expiry, reset сессии,
  два реальных процесса и rollback прошли проверки.
- [x] Схема развёрнута с пустой локальной базы, schema validate зелёный;
  production миграция применена штатной процедурой и версия подтверждена.
- [x] Выполнить безопасные публичные smoke-запросы: версия, 401 без
  Bearer, 403 для чужого Origin, 405 для GET logout. Реальные аккаунты
  не сбрасывать и их факторы/резервные коды не читать ради проверки.
- [x] Собрать постоянный итоговый отчёт с уникальными принятыми/отклонёнными
  замечаниями каждого прохода и ссылками на PR/CI; локальные var-артефакты
  не считать единственным архивом доказательств.

## Чек-лист готовности

- [x] Для каждой угрозы есть тест поведения и фактический результат.
- [x] Все необходимые ревью завершены, принятые замечания исправлены.
- [x] CI и поставка окончательного diff успешны, ограничения названы.
- [x] Пользовательский исходный отчёт сохранён без изменений.
- [x] Нет заявления, что артефакт extension автоматически обновил все
  браузеры или что агент подключил MFA владельцу без его authenticator.
- [x] Итог содержит действия пользователя: обновление расширения и личное
  подключение authenticator при следующем входе администратора.
