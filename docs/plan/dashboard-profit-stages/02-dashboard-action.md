# Этап 2. Прибыль в сценарии dashboard

## Подробный план

1. Добавить в `BuildDashboardSummaryActionTest` сценарии известной прибыли 35000, неизвестной цены, неполноты, нулевого полного периода, исправления цены и валютной ошибки. Подтвердить RED до изменения сценария.
2. Дополнить Application DTO полями прибыли и новым `DashboardProfitDetails`; данные периода связываются с агрегатами этапа 1.
3. Прочитать итоги и дни в текущей read-only транзакции; проверить единую валюту и ошибки валюты цены до денежного сложения.
4. Рассчитать известную прибыль через Money, при неполноте/неизвестной цене передавать null для всего периода и его ряда. Дни без начислений полного периода — нули.
5. Дополнить изменения только полем `profitBps`, не скрывая остальные показатели при неизвестной себестоимости.
6. Выполнить интеграционные тесты, unit и backend-гейты, записать результаты.
