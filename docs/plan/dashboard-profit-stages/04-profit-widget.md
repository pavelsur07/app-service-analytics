# Этап 4. Карточка прибыли

## Подробный план

1. Обновить типизированные тестовые ответы для нового API, явно задавая данные profitDetails.
2. Добавить RED сценарии карточки: прибыль/убыток, недоступный ряд, единственный ряд сравнения, недостающая себестоимость и ссылка, неполная загрузка, правка цены, нулевая база.
3. Добавить profit после sales в декларативный список; настройки и счётчик используют общий список из девяти карточек.
4. Адаптировать WidgetCard к nullable-рядам целиком, ReactNode-пояснению, пустым rows и корректным доступным подписям графика.
5. Добавить ProfitHint с границами показателя и причинами недоступности; пустое состояние главной учитывает hasAccruals, включая взаимно погашенные начисления.
6. Проверить совместимость сохранённых настроек, компаний и исходных восьми карточек.
7. Выполнить seller Vitest, typecheck, lint, knip и build.
