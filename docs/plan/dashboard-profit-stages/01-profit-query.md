# Этап 1. SQL-агрегаты прибыли

Основная спецификация и значения тестов: [этап 1](../dashboard-profit-widget.md#этап-1-реализовать-sql-расчёта-начислений-и-себестоимости).

## Подробный план

1. Добавить интеграционные тесты нового `DashboardProfitQuery` на существующих Builder: знаки начислений, расходы кабинета, историческая себестоимость и quantity, возврат другого месяца, неполная история, отсутствующая/нулевая цена, изоляция, валюты, границы и большие целые суммы.
2. Запустить новый набор до реализации и подтвердить отсутствие Query-класса.
3. Реализовать readonly DTO итогов/дней и QueryBuilder двух непересекающихся периодов. Общий SQL подбирает цену для каждой строки выручки; все строки ленты суммируются ровно один раз.
4. Использовать numeric до умножения, проверять диапазон int при маппинге, сигнализировать несовпадение валют отдельно.
5. Повторить новый набор, затем проверки backend. Исправлять причины ошибок, не ослабляя правила.
