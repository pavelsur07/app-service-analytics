1. Расширить HTTP-тест изоляции: собственные расходы попадают в детали прибыли; чужие расходы исключены, неполный период содержит явный null прибыли и дневного ряда.
2. Подтвердить RED до изменения ответа.
3. Дополнить Response DTO и from-мапперы: profitMinor, profitBps, дневная прибыль, объект profitDetails с методом manual, качеством и компонентами.
4. Описать nullable и исходные знаки в PHP-документации схемы.
5. Выполнить make api-doc-export api-types и make api-types-check; проверить отсутствие непредусмотренных изменений контракта.
6. Выполнить функциональные тесты, PHPStan и стиль.
