# Озон Ads: паспорт стенда этапа 04 для приёмки 11 (observe)

08.11.2026. Зафиксирован **до первого замера** по поручению «продолжай».
Это инженерный профиль локального mock-стенда. Не допуск реальных кабинетов,
не согласованный денежный риск и не гарантия задержки данных Ozon.

| Параметр | Нормальный | Пиковый | Основание |
|---|---|---|---|
| Кабинеты / кампании | 10 / 100 | 100 / 1000 | Проверочная ступень; до 10 политик/кабинет — текущий предел кода |
| Работники | 4 | 4 (и 2 экземпляра × 4 для конкуренции) | Текущий production wiring, 1 захват/работник/с |
| Интервал Ozon | 600 с | 600 с | Текущий нижний предел; ранних повторов быть не должно |
| Mock HTTP | 5 мс/запрос, локальный httptest | то же; отдельно зависший кабинет | Синтетическая задержка; не оценка Ozon |

Массовая смена лимита отдельно рассчитывает предполагаемый budget stop по всем
кампаниям из сохранённого расхода, с теми же порогами 5/35 с и нулём новых HTTP
до разрешённого интервала. Этот сценарий зафиксирован до его первого запуска;
проверка настоящей остановки показов сюда не входит.

Точка измерения: монотонная длительность от момента перед первым Apply
(консервативно раньше сохранённого общего due) до успешного Finish каждой
кампании, включая применение конфигурации. Календарная дата синтетическая,
таймеры/HTTP и ожидания настоящие. Публикуются n, p50/p95/p99/max в целых мс;
одна конечная выборка не доказывает многосуточный SLO. Порог не меняется после
результата: неудача требует исправления или нового явно названного профиля.

Аварии: PHP/публикация недоступны, 401/403/429/5xx, зависший HTTP одного
кабинета, отзыв/ротация/истечение grant, пустые/вчерашние данные, квота,
потеря аренды/рестарт/две реплики, недоступность своей БД, сдвиг часов.
Тесты не подключаются к настоящему Ozon и не используют Redis/Messenger.
Команды start/stop отсутствуют, их SLO и rollback не объявляются проверенными.

Локальная квота контроллера 70000/24ч остаётся защитой только его экземпляров.
Существующий ozon-fetcher использует свой account/endpoint limiter и не
разделяет этот счётчик. Область общего HTTP-лимита/организация/прочие потребители
ещё не установлены; это блокирует живой этап 12. Ozon повторно подтверждает
исключения для оперативных CPC/SKU, но не даёт нашей системе общего остатка:
[официальная новость 08.06.2026](https://dev.ozon.ru/news/740-Performance-API-metody-dlia-otchetnosti-bez-raskhoda-limitov/),
[ограничения 14.09.2026](https://dev.ozon.ru/news/794-Performance-API-vvedenie-ogranichenii-na-kolichestvo-zaprosov/).
Основной раздел Limits снова не отдал читаемый текст; численные лимиты берутся
из ранее предоставленной владельцем выдержки, не из неполученной страницы.
