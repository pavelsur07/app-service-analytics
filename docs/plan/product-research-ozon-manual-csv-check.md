## Что сравнивалось

Ручной файл: UTF-8 BOM, `;`, 41 колонка A–AO, 62 148 строк и уникальных SKU.
Смешанная схема заголовков: русские и английские названия.

Период 01.02.2025–28.02.2025 принят по имени файла. Сам CSV не содержит
отдельного заголовка параметров. Пользователь подтвердил режим FBO+FBS.
Категория запроса API:
`Бытовая химия и гигиена/Бытовая химия/Защита от насекомых`.
Колонка «Категория» в ручном файле пустая; путь установлен по колонке Niche
и названию файла. Внутри выборки встречаются несколько ниш — не вычищались.

Получены свежие полные API CSV для FBS=1 и FBS=0 и первые 500 JSON-строк
каждого режима. Валюта RUB, пустые фильтры, сортировка revenue DESC/id ASC.
Все запросы — прямой REST с заголовком авторизации; токен в файлы не включён.
Сопоставление по SKU, без зависимости от порядка строк. Числа — Decimal;
десятичная запятая и разные форматы даты разобраны явно. Значения не исправлялись.

| Источник | Строк / уникальных SKU | Продажи, шт. | Выручка, RUB |

Наборы SKU всех трёх файлов совпадают полностью. Продажи и выручка ручного
CSV совпали с API FBS=0 по каждой строке, а не только по общей сумме.
С API FBS=1 продажи/выручка расходятся на 14 347 SKU.

Это наблюдение не отменяет сообщения пользователя, что в UI выбраны FBO+FBS.
Установлено расхождение между выбранным режимом и значениями экспорта;
его причина не доказана. Нельзя менять методологию на FBS=0 для прохождения
приёмки. Нужны проверка запроса/экспорта интерфейса либо разъяснение MPStats.
Возможные объяснения (не факты): отличие трактовки режима, другой путь
экспорта/версия API, не применившийся флаг либо различие снимков.

## Поля

Все 41 поля ручного CSV найдены среди 62 полей REST. API CSV содержит 49
колонок; это другой формат представления. Полная карта и количество
расхождений каждого поля — [в карте колонок](product-research-ozon-columns.md).

При диагностическом FBS=0 совпали 29 из 41 колонок на всём наборе строк.
Оставшиеся различия:

| Поле API | Строк с различием |
|---|---|
| category / category_position | по 2 403 |
| categories_count | 20 043 |
| name / seller | 128 / 1 |
| balance / balance_fbs | 83 / 12 471 |
| turnover_days | 4 893 |
| frozen_stocks / frozen_stocks_cost / frozen_stocks_percent | по 197 |
| thumb | 62 148 |

Для thumb имена файлов изображений совпадают у всех SKU; отличается путь
размера превью (например, наличие d100). Это различие URL, не отсутствие поля.
В turnover_days встречаются небольшие различия значений, например 13.34/13.33;
их нельзя списывать на формат десятичной запятой. Имена/категории/остатки могут
зависеть от времени снимка, но источник расхождений пока не установлен.

Уточнения схемы: ручной Niche — текстовый путь; ручной Turnover — дни
оборачиваемости; First Date — ISO-дата. Наличие строки FBS=1 не доказывает
значение переключателя отчёта: это признак товара, не метаданные запроса.
