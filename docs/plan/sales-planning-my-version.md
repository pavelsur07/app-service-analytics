## 1. Что планируем
- **Цель плана** - мотивация, прогноз закупок-подсорта. в версии 0.1 можно его менять
- **Метрики** - маржа, свободная маржа ( маржа в касса-счет минус остаток товара по себестоимости) GMROI
- **Определение продажи** - выкуп с учетом возвратов
- **Дата события** — выкуп-доставка

## 2. Структура плана
- **Измерения:** период × канал (магазин) × товар/категория
- **Уровень ввода и уровень анализа** — вводят обычно сезон (возможно месяц) × категория/SKU, анализируют по дням и неделям.
- **Декомпозиция вниз** - месяц раскладывается на дни по правилу: по сезонному профилю ( прошлому году или аналитика)
- **Согласованность уровней** - сумма нижнего уровня равна верхнему. Сборка снизу (bottom-up).

## 3. Основа для цифр
- Прошлые данные: аналитика площадок если есть тот же период прошлого года + тренд последних месяцев.
- Сезонность, праздники, акции площадок.
- Ограничения: остатки и поставки. Без товара план недостижим — план продаж связан с планом закупок.
- Известные события: запуск новинок, вывод товаров, изменение цен, рекламный бюджет.
