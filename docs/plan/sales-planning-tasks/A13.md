# A13 — количество и область чтения

## План до изменения кода

Проверить недостающее поведение `SalesCohortMetricsQuery` на реальной тестовой БД,
используя `SalesFactBuilder` и репозиторий. Существующие A11/A12 уже проверяют
изоляцию компании/аккаунта/SKU/даты и частичный T1; эти сценарии не дублировать.

1. Добавить пакет нескольких SKU и дат: перемешанная запись, агрегирование
   нескольких фактов одного дня, сортировка SKU и вложенных дней, отсутствие
   выдуманных строк для отсутствующего SKU и пропущенного дня.
2. Проверить допустимую границу одновременно 50 SKU и 184 календарных дней:
   все 50 SKU возвращаются, один содержит 184 фактических дня, остальные —
   только собственные фактические дни. Проверить включение концов диапазона.
3. Проверить календарные даты при разных времени и часовых поясах входа:
   использовать значения, UTC-нормализация которых изменила бы Y-m-d, а также
   диапазон одного дня с обратным порядком моментов времени.
4. Проверить количества и равенство raw = effective + T1 в возвращённых днях.
