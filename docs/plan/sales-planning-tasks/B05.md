## Общие ограничения

- `pGrossPre=G/(T1+G+T2+P)`, G=D+R, неDnet. T1 сохраняется вtraining
  даже при исключении известныхT1 из ActualOrdered вUI. Не использовать
  старые D-rates/возрастные поправки ADR-032 как новыйgross. Возрастной
  gross modifier/assigned delivery date/future unplaced orders не вводятся.
- Eligible target — уже размещённые, известные открытые до передачи штуки
  на том же current readonlyRR/readAt/capturecontext. Target evidence —
  typed contract будущего B09producer, не реализация SQL/истории.
- Начальная пригодная sample минимум100units/30distinctpostings, пороги
  включительные. Отсутствующийp95/source inputComplete/unknown данные
  не заменяются назначенным сроком илинулём. p950 допустим при sourceproof.
- Согласованность raw counts: nonnegative, суммы T1/G/T2/P равныsampleQty,
  counts/postings возможны; проверять без int overflow даже при bad inputs.
- Whole SKU estimate→sameaccount estimate→null, все raw components/sample/
  diagnostics/context одной выбраннойrow, без смешения числителей/denominator.
- CompanyId первым, accountId следующим; чужие target/batch/context
  отбрасывать до metadata/zero shortcuts. Требуется nonempty RRsnapshot и
  полный samecontext fingerprint/readAt; исторический watermarkB15 не выдумывать.
- Trusted eligibleOpenQty0 →quantity0 безfakep0 ибезtraining; null/unknown/
  incomplete/contradictory quantity не даёт numeric0. GenuineG0 с достаточной
  пригодной sample может дать empiricalp0, отличать от неизвестнойвыборки.
- Exact expectedGrossQty=eligibleOpenQty*pGrossPre;0<=expected<=eligible,
  no float/rounding/int products overflow. Установленныйbrick/math0.19
  разрешён вIngestionDomain черезB04Deptrac; библиотечные типы держать private,
  public exact quantity numerator/denominator decimalstrings допустимы.
- B06 отдельно реализует post-handover вероятностьG/(G+T2+P) иconditional
  sample guard с dedicatedpostHandoverPostings. Здесь не выполнятьB06; можно
  предусмотреть явную stage discriminator/расширяемый контракт без её расчёта.
- Future return factor(1−F(H)) иnetretained относятсякB07, unknown/fallback
  интеграцияB08, actualtargetreaderB09, moneyB11/APIUI/quality/rollout позже.
- Никаких новых SQL/схемы/writers/конфигурации/библиотек/Facade/API/UI,
  B02–B04sourcecontracts не менять без конкретнойнеобходимости.
