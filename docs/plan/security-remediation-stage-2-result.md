## Результат и TDD

Централизованная защита cookie-контуров выполняется до firewall login/logout.
Изменяющие запросы требуют X-Conwix-Request: 1, точного Origin своего контура
либо проверенного Referer при отсутствии Origin. Непустое тело — только JSON,
включая разобранный PHP multipart. GET logout возвращает 405 и сохраняет
сессию. Пути декодируются тем же способом, что в Symfony. Bearer extension
и internal исключены только по своим точным префиксам, а не заголовку.

Клиенты seller/admin отправляют защитный заголовок, включая пустые POST
и DELETE. OpenAPI и TS пересозданы из программного describer, вручную
сгенерированные файлы не исправлялись. Test helper моделирует штатный клиент;
негативные тесты используют исходный WebTestCase без заголовка по умолчанию.
localhost разрешён только в test-конфигурации; production origin только
соответствующий HTTPS conwix.com, задаётся явно, без доверия Host.

RED: 18 HTTP-сценариев и оба клиента подтвердили отсутствие защиты.
Дополнительный контрактный тест не находил обязательный заголовок.
После замечаний ревью новые тесты воспроизвели encoded-path обход и
multipart logout; исправления проверены RED→GREEN.

## Условия поставки и ограничения

Код и тесты проверены; для завершения поставки нужны зелёный CI окончательного
коммита, merge/deployment и smoke. Клиент с заголовком совместим со старым
сервером. При включении ограничения старым открытым вкладкам потребуется
обновление; 403 не повторяется бесконечно и выводится стандартным API error UI.
SameSite/IP allowlist сохранены, но сами по себе защитой от sibling-origin
не считаются. Отсутствие Origin/Referer допустимо только со специальным
заголовком и закрытым CORS.
