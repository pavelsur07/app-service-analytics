## cf2a569e5893, 5B

Пакет SHA-256: `cf2a569e5893dcb227fec3793734d0abc1549dea57600ac637a758f269627c1a`.
Артефакт: `var/review/runs/20261101T041855.795745Z-cf2a569e5893-defects-hje6yel1/`.

Замечание 1, принято: Режим вложений разыменовывает символьные ссылки: is_file(), stat() и read_bytes() работают с целью ссылки, хотя check_path разрешает ссылку только как самостоятельный Git-объект. Ссылка внутри tests/fixtures на закрытую выгрузку размером более 32 KiB скопирует её содержимое во вложение внешнего ревью вместо передачи самой ссылки. Нужно исключить symlink из этой ветки и сохранить его обычный Git diff.

Замечание 2, принято: При исключении вложения из Git diff теряются режимы файла: описание before/after содержит только байты, размеры и hashes, а name-status режима не отражает. Если после подготовки пакета изменить executable bit уже добавленного или изменённого большого файла фикстуры, повторный build вернёт тот же пакет. Проверки свежести до и после ревью примут изменившийся Git-снимок. Нужно сохранять Git mode обеих версий вместе с вложениями либо оставлять соответствующие заголовки diff.
