# Матрица спроса, этап 4 — экран

Общий план — `ozon-demand-matrix-report.md`; API — этап 3.

## Задача

Экран `/companies/{id}/demand-matrix` в `apps/seller`: продавец видит,
в каких кластерах покупают каждый товар, как меняется спрос и каким
ячейкам нельзя верить из-за отсутствия товара.

## Решения этапа

- **Страницы — «Назад / Дальше» со стеком курсоров**, как у «Остатков»,
  а не бесконечная подгрузка: одинаковое поведение соседних отчётов,
  ссылка на страницу живёт в URL.
- **Поиск — форма с кнопкой «Найти»**, как в «Прогнозе и факте по SKU»:
  запрос уходит по отправке, а не на каждую букву; `maxLength=100`,
  как на сервере. Поиск и курсор — в URL.
- **Ячейка:** спрос в день крупно, доля мелко; фон — по доле, 4 ступени
  акцентного цвета (`<10%`, `10–25%`, `25–50%`, `≥50%`); дефицит —
  значок и «без товара N дн» в подписи и `title`, тренд ячейки —
  в `title`. Пустая ячейка без дефицита — пусто, с дефицитом — «?»:
  спрос неизвестен.
- **Тренд SKU** — отдельная колонка: «+60%», «−20%», «0%»; `null` —
  прочерк с подсказкой «меньше N заказов».
- **`formatDemand` переезжает в `shared/lib`** — второй потребитель
  (матрица) после «Остатков»; поведение и тесты прежние.
- **Пункт меню «Спрос»** — рядом с «Остатками».

## Результат

`apps/seller/src/features/demand-matrix/`:
- `lib/demandMatrixFormat.ts` (+ тест) — тренд, доля, ступень фона, подпись ячейки;
- `lib/demandMatrixParams.ts` (+ тест) — поиск и курсор из URL и в URL;
- `model/useDemandMatrix.ts` (+ тест) — ключ кэша через
  `companyQueryKey(companyId, 'ingestion', 'demand-matrix', params)`,
  путь запроса, разбор 422 через `msw`/`openapi-msw`;
- `ui/DemandMatrixPage.tsx`, `ui/DemandMatrixTable.tsx`;
- маршрут в `app/Root.tsx`, пункт в `app/Sidebar.tsx`;
- `shared/lib/formatDemand.ts` (+ тест); `docs/structure.md`.

## Чек-лист приёмки

- [ ] ключ кэша содержит компанию, поиск и курсор; у двух компаний — разные;
- [ ] форматирование тренда, доли, ступени фона — чистые функции с тестами;
- [ ] предупреждение о неполной загрузке видно при `incompleteSalesAccounts > 0`;
- [ ] `make front-typecheck front-lint front-test front-knip APP=seller` зелёные;
- [ ] `make front-build APP=seller` — порог размера бандла не превышен;
- [ ] экран открыт на dev-сервере с данными: колонки, ячейки, дефицит,
      страницы и поиск работают. В песочнице 2026-10-23 браузера нет,
      а образ Playwright не помещается на диск (свободно 1,8 ГБ): проверен
      ответ API через dev-прокси после входа; взгляд на экран — на проде
      после выкладки (этап 5).
