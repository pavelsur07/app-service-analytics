# docs/design/README.md

Эталонные макеты дизайн-системы. Не исходник сборки: код из них
не генерируется, они читаются человеком и агентом при выделении
компонента.

Реализованные токены живут в packages/ui/src/theme.css — он источник
правды для кода. При расхождении с макетом правится код, а расхождение
разбирается: макет мог уйти вперёд, а мог и разойтись случайно.

## Как обновлять

1. Новый макет кладётся отдельным файлом, старые не перезаписываются.
2. Строка в таблице выше — обязательна, иначе версия бесполезна.
3. Перенос в код — отдельная задача. Пункт «перенесено в код» заполняется
   по факту, а не авансом.
4. Черновики итераций сюда не кладутся: файл весит около 110 КБ.
