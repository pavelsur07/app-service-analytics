# _contracts — межсервисные контракты

Единственный источник форматов данных между сервисами `services/` и PHP
Conwix. Правила — `services/AGENTS.md` §3.

## Версионирование

- Контракт — каталог `<contract>/v<N>/` со `schema.json` и `CHANGELOG.md`.
- Опубликованная версия неизменна: правка поля или семантики — новая
  версия; производитель и потребитель переходят независимо.
- Обе стороны проверяют сообщения по схеме тестом: производитель — свой
  ответ, потребитель — разбор эталонного (`example.json`).

## Индекс

| Контракт | Версии | Стороны | Статус |
|---|---|---|---|
| [marketplace-connections](marketplace-connections/v1/) | v1 | производитель: PHP (сервисный контур, ADR-043); потребитель: `services/*` | **проект** до этапа 4 |
| [product-research-ozon](product-research-ozon/v1/) | v1 | Symfony ↔ Python, company scope | схемы действуют; операции до реализации возвращают not_available |
| [service-coverage](service-coverage/v1/) | v1 | производитель: `services/*` (`GET /internal/coverage`); потребитель: PHP (экран «Покрытие GO» админки) | действует |

Контракт выдачи фактов (`source-fact-envelope` ВашФинДир) не перенесён:
передача данных сервиса в PHP — вторая волна, отдельный ADR.

- [ozon-ads-observe v1](ozon-ads-observe/v1/CHANGELOG.md): полная выдача политик и подтверждённая проекция наблюдения, без команд.
