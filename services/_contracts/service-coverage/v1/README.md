# service-coverage v1

Стандартный endpoint покрытия данных — `GET /internal/coverage` — у каждого
сервиса `services/` (ADR-043 п. 4, `services/AGENTS.md` §2). Потребитель
в PHP — экран «Покрытие GO» админки (`OzonFetcherCoverageClient`), токен
«PHP → сервис».
Schema: [schema.json](schema.json). Эталон: [example.json](example.json) —
его проверяют по схеме обе стороны, PHP разбирает его своим клиентом.
История: [CHANGELOG.md](CHANGELOG.md).

## Запрос

`GET /internal/coverage?from=YYYY-MM-DD&to=YYYY-MM-DD`, заголовок
`Authorization: Bearer <токен «PHP → сервис»>`.

- Без параметров — окно, которое сервис ведёт (у ozon-fetcher — M-2…конец M по МСК).
- 422 `invalid_period` — кривая дата, `from > to` или окно шире 93 дней.
- 401 — нет или неверный токен.
- 503 — сервис ещё не получил ни одного снимка подключений (сразу после
  старта): пустой ответ в этот момент неотличим от «подключений нет».

## Семантика

- Строка — `resource_type × period_key`; в ней число кабинетов по статусам
  задач загрузки. Нет строки — по этому периоду задач нет (день не
  наступил или не запланирован).
- `period_key`: `YYYY-MM-DD` — дни окна; `YYYY-MM` — месяцы, на которые
  попадает окно; `ref` — справочник (не зависит от периода).
- `cabinets_expected` — сколько активных кабинетов должно иметь этот ресурс:
  seller-ресурс — кабинеты с ключом Seller, реклама — с ключом Performance.
  Разница с суммой `by_status` — кабинеты без задачи («не загружено»).
- `cabinets_total` — активные кабинеты с ключом Seller: запасное
  «ожидается» для seller-ресурса, у которого строки нет. Кабинет только
  с ключом Performance в него не входит и учитывается в `cabinets_expected`
  рекламных строк.
- Учитываются только активные кабинеты текущего снимка: задачи
  отключённых кабинетов не считаются.
- Статусы — у ozon-fetcher это статусы `fetch_task`: `done`, `running`,
  `pending`, `not_ready` (отчёт ещё не сформирован источником),
  `failed_retryable` (повторится), `failed_permanent` (нужен человек).
- Идентификаторов кабинетов, компаний и сумм в ответе нет — только счётчики.
